# AVOS Genesis Platform Ultra Mega Pack 1

Version: 1.0.0

This platform provides a governed, blueprint-driven foundation for generating
systems and architectural artifacts inside AVOS.

## Core principles

- Foundation First
- Capability First
- Blueprint Driven
- Human Final Authority
- Audit by Design
- Reversible Planning
- Autonomous execution disabled

## Main endpoints

- GET `/genesis-platform/status`
- GET `/genesis-platform/verification`
- POST `/genesis-platform/smoke`
- POST `/genesis-platform/sessions`
- GET `/genesis-platform/sessions`
- POST `/genesis-platform/sessions/:id/decision`
- POST `/genesis-platform/sessions/:id/execute`
- GET `/genesis-platform/blueprints`
- GET `/genesis-platform/artifacts`

Execution remains blocked until an explicit human decision is recorded.
