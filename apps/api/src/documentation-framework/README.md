# AVOS Documentation Framework - Mega Pack 1

Version: ADF-MP1-1.0.0

## Purpose

Establish documentation as a first-class Foundation capability in AVOS.

## Endpoints

- GET `/avos/documentation/status`
- GET `/avos/documentation/documents`
- GET `/avos/documentation/documents/:id`
- POST `/avos/documentation/register`
- PATCH `/avos/documentation/documents/:id`
- POST `/avos/documentation/validate`
- GET `/avos/documentation/search?q=...`
- GET `/avos/documentation/metrics`
- POST `/avos/documentation/verification/run`
