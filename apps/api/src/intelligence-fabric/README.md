# AVOS Intelligence Fabric IF-1

Foundation layer for converting trusted AVOS knowledge into signals, insights,
reasoning, decisions, recommendations, metrics, verification, smoke testing,
and certification.

## Endpoints

- `GET /avos/intelligence-fabric/runtime/status`
- `GET /avos/intelligence-fabric/signals`
- `GET /avos/intelligence-fabric/metrics`
- `POST /avos/intelligence-fabric/analyze`
- `POST /avos/intelligence-fabric/verification/run`
- `POST /avos/intelligence-fabric/smoke/run`
- `POST /avos/intelligence-fabric/certification/certify`
- `GET /avos/intelligence-fabric/certification/status`
