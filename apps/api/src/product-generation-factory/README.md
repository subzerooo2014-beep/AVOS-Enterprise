This module implements the real product-generation pipeline:

1. Product Compiler Core
2. Architecture Generator
3. Backend Code Generator
4. Database & API Compiler
5. Frontend Generator
6. Test & Repair Engine
7. Deployment Factory
8. Final Runtime Integration & Certification

Generated products are written to:

`.avos/generated-products/<namespace>`

Each generated product includes:

- NestJS backend source
- Prisma schema
- OpenAPI document
- Next.js frontend
- generated smoke tests
- Dockerfiles and Docker Compose
- GitHub Actions CI
- rollback documentation
- AVOS Digital DNA and runtime contract
- final certification record

Human Final Authority and the Global Compliance Readiness Gate remain mandatory.
