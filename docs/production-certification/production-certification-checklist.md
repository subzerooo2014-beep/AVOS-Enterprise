# AVOS Production Certification Checklist

## Required approvals

- QA approval
- Security approval
- Operations approval
- CTO approval
- Executive approval

## Required evidence

- Successful production build
- TypeScript validation
- Flutter analysis
- Smoke test results
- Integration test results
- Security certification
- Performance certification
- Compliance certification
- Load test evidence
- Business continuity evidence
- Release candidate manifest
- Production certificate

## Release rule

A release may only be certified when every required quality gate and approval has passed.
